# AgentX

**The unified gateway to MetaComp services — built for AI agents.**

---

## What is AgentX?

AgentX is the core layer that connects MetaComp's full suite of financial services into a single, agent-ready interface. Where traditional APIs were designed for software engineers to integrate manually, AgentX is designed from the ground up for AI agents to discover, call, and compose MetaComp capabilities autonomously.

Whether an agent needs to assess transaction risk, verify compliance, initiate a payment, or query settlement status — AgentX is the single entry point that handles it all.

---

## Why AgentX?

The rise of AI agents is changing how software interacts with financial infrastructure. Agents don't read documentation — they need tools that are self-describing, composable, and safe to call autonomously. AgentX is MetaComp's answer to this shift:

- **One connection, all services** — a single MCP server exposes the full MetaComp platform; no juggling multiple endpoints or credentials
- **Agent-native design** — tools are structured for LLM reasoning: clear intent, minimal required input, deterministic output
- **Compliance by default** — every action routes through MetaComp's licensed infrastructure, so agents operate within regulatory boundaries without extra configuration
- **Composable workflows** — agents can chain services together: check a wallet's risk, then route a payment, then confirm settlement — all in one autonomous flow

## The Bigger Picture

MetaComp holds a **Major Payment Institution (MPI) license** from the Monetary Authority of Singapore (MAS). AgentX is the bridge between that regulated infrastructure and the emerging world of autonomous AI agents.

We believe the next generation of financial workflows won't be triggered by humans clicking buttons — they'll be orchestrated by agents making decisions in real time. AgentX is the infrastructure layer that makes that possible, safely and compliantly.
